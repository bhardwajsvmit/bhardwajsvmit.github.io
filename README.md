<h1 align="center">
  Portfolio Website
</h1>
<p align="center">
   <a href="https://bhardwajsvmit.github.io/" target="_blank">bhardwajsvmit.github.io</a> built with <a href="https://nextjs.org/" target="_blank">Next.js</a> + styled-components, deployed to <a href="https://pages.github.com/" target="_blank">GitHub Pages</a> via GitHub Actions.

## Development

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```sh
npm run build
```

Produces a static export in `out/`. Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds and publishes `out/` to GitHub Pages automatically.
